Leer o recibir una explicación no demuestra competencia. «Con ayuda» conserva el intento; «Sin ayuda» exige repetir sin pistas; «Transferido» aplica lo aprendido a otro cambio. Done exige evidencia, además de Sin ayuda o Transferido para aprendizaje. El resultado es un registro declarado que debe revisar una persona.

Autoguardado local por navegador y origen. Exporta JSON para entregar tus cambios al agente. El JSON incrustado en este HTML es el registro durable del repositorio; el agente no ve automáticamente tus ediciones locales. Importar combina por id y updatedAt; gana la fecha más reciente, y en empate se conserva el registro actual. Las actualizaciones de otra pestaña usan la misma regla. Guarda una copia HTML para llevar el estado completo sin conexión. En file:// la persistencia depende del navegador; conserva una exportación.
