## Stopped before consign

D2's pass condition includes consigning web stock. That needs a hub catalog, a store receiving and a manager on the store.
- No shipped route removes or retires a catalog item (`POST` routes: `/catalog/import`, `/catalog/items`, `/catalog/products`, values; no delete).
  Test items imported into `savia` would stay in the production catalog. Web stock itself can be returned (`POST /web-stock/release`).
- The owner's and staff's logins are not known; inventing them would leave rows that `--provision-staff` cannot rename.
- So consign waits for the real catalog (W8) and the real people. No direct SQL was used.
