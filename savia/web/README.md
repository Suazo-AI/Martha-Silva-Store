# SAVIA staff web

Plain ES modules, Spanish UI, existing SAVIA 08 tablet design.
Start the local pilot with `python savia/tools/pilot.py up` and open http://127.0.0.1:5080/.
See [WEB.md](../docs/pilot/WEB.md) for the screen flow, verification and limits.
The API itself hosts this folder; no separate web server or package installation is needed.
